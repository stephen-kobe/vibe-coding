# Kit d’amorçage Vibe Coding

Ce dossier est la source du kit distribuable. Exécuter `scripts/build-starter-kit.py` depuis la racine du dépôt pour produire les archives dans `outputs/`.

Le kit ne contient ni secrets, ni dépendances applicatives, ni versions de runtime inventées. Son initialiseur exige les versions PHP et/ou Python afin que chaque projet démarre avec une décision explicite et traçable.
